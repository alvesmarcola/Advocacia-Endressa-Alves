# Landing page - Social Media Eduarda Alves

Este projeto é uma landing page para uma social media individual. Ele foi desenvolvido com desempenho e responsividade em mente, seguindo os padrões de acessibilidade. Com uma interface fácil de usar e design moderno, a página permite que os visitantes obtenham informações sobre os serviços oferecidos pelo profissional, entrem em contato e sejam direcionados para as redes sociais. Tudo isso garantindo uma boa performance e uma boa experiência do usuário.
